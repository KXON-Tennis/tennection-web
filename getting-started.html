Tennis Nut 快速入門

做完這六件，App 就會開始替你做事——球場有狀況會提前告訴你、 球友到球場你會知道、卡住的時候有人可以問。

底下五個分頁由左到右是：首頁、諮詢、中間那顆綠色的 ＋、 探索、護照。下面每一步都會說清楚在哪一個分頁。

0. 先把 App 裝起來

Tennis Nut iPhone 在 App Store 上就下載得到。 Android 使用者？加入 Google Play 測試 →

1. 設定裝備

在 護照 分頁往下滑到最底，有一區叫 我的球袋，分成 球拍 和 球鞋，各自右邊有一顆 ＋ 新增。

球拍可以用拍的

按 ＋ 新增之後，最上面有一顆 掃描球拍。對著拍子拍一張， 品牌、系列、年份就會填好，你只要確認一下。

手動填的話，必要的其實只有品牌和系列。穿線的部分建議填：填了穿線日期， 到該換線的時候護照上那支拍子會自己標「建議重新穿線」。

球鞋只有四格

品牌、型號、年份、開始使用日期，四格填完就好。

加一支拍或一雙鞋各拿 +5 🌰。 球袋上限是 5 支拍、3 雙鞋；淘汰的可以標成「已淘汰」，收進另一層，不佔名額。

填了之後會怎樣

  • 長按可以把一支設成 主要球拍／主要球鞋，護照上會有個「主」字
  • 你的球友看得到你的主拍和主鞋（品牌、型號、年份）
  • 球袋上方有一個 大家的裝備心得，寫一篇所有人都看得到—— 被三個不同的人按「有用」，拿 +10 🌰

2. 加好友

護照 分頁的 我的好友，或中間那顆 ＋ 裡的 加球友， 兩個入口到的是同一頁。

面對面：掃一下就好

  1. 你按 我的條碼，把畫面拿給對方
  2. 對方按 掃描，對著你的畫面掃一下
  3. 掃完就加好了

不在同一個地方

按 或傳我的 ID 邀請他，會跳出分享選單，用 LINE 傳過去就好， 訊息裡有你的 8 碼 ID。反過來，別人把 ID 傳給你的話， 那一頁下面有一張 已經拿到球友的 ID 了？，貼上去按 加好友。

加了之後，六件事會不一樣

他到球場，你的手機會響

推播寫「○○○ 現在在 ×× 球場打球」。想找人打球的時候，這是最有用的一則通知。

首頁多一塊「球友動態」

好友這一週練了什麼、打了什麼比賽，直接列在你的首頁上。

看得到他的護照

練習時數、比賽勝率、去過哪些球場、拿了哪些成就、還有他的主拍主鞋。

約球可以只給好友看

開一場約球時，「誰看得到」可以選 只有好友，也可以在「找誰」裡直接點名。

有空的時段會對得起來

你和好友都標了有空的時段，App 會算出「和你重疊 N 小時」。

比賽一次記，兩個人的戰績都留下

記比賽時把對手標成好友，他確認之後，這場球也會進他的護照。

加好友之後會多出什麼 →

3. 標記最愛的球場

在 探索 分頁點開任何一座球場，卡片右上角有一顆 愛心，按下去就是。 再按一次取消。

另一條路是自動的：同一座球場去過兩次之後，App 會自己問你 「這座球場看起來是你的主場」，按 釘成主場 就好。

這顆愛心做了四件事

  • 球場出狀況會通知你——有人回報客滿、溼滑、損壞、暫停開放， 你會在出門前就知道
  • 有人在那裡打球會通知你——不限於好友
  • 陌生人開在那裡的公開約球，會出現在你的首頁——把常去的球場 加進最愛，那裡的球局就會自己找上你
  • 首頁的 我的最愛球場 卡片會列出這幾座場，各自顯示現在幾個人在打
那顆愛心到底做了什麼 →

4. 地圖怎麼看

探索 分頁就是地圖。上面最搞不清楚的是點的顏色，先講這個。

顏色是場地材質，不是狀態

藍色是硬地、橘紅是紅土、綠色是草地、紫色是 PU⋯⋯ 灰色的是還等著有人補上材質的場地，你可以順手補（見下面）。

只有三種情況顏色會被蓋掉：現在有人在打球會變成亮橘色、 客滿或溼滑變黃、損壞或暫停開放變紅。點的上方會直接寫「3 人在打」或狀態文字。

上面那排篩選

球友在線（現在有人的球場）、我的最愛、球隊、 已拜訪、室內。右邊還有切換底圖、定位、和更完整的篩選 （場地類型、縣市、國家）。搜尋框可以打球場名，也可以打地址或地標。

點開一座球場

裡面由上而下是：

  • 紀錄 和 導航 兩顆按鈕——「紀錄」會直接帶著這座球場開練習表單
  • 幾面球場、材質、免費或付費、有沒有燈、室內或室外
  • 目前狀況和最後更新時間
  • 約球——這裡有沒有人約球，以及 約在這裡
  • 誰有空、駐紮在這裡的 球隊團體、這座球場辦過的盃賽

打卡是自動的

你到球場待滿五分鐘，App 會自己記一筆，給 +1 🌰。 如果 App 開著，會跳一張「你在 ×× 打球嗎？」，按 確認 再拿 +2 🌰。離開之後它會問你要不要把這次記下來。

順手回報，球場資料才會長出來

中間那顆 ＋ 裡的 報告球場狀態，有兩種：

  • 即時狀態回報（溼滑、客滿、損壞這類當下的事）+5 🌰 ——需要人在球場 200 公尺內，每座球場每天一次
  • 基本資訊勘誤（名稱、地址、燈光、面數這類不會變的）+15 🌰

地圖上少了一整座球場的話，右下角有 新增球場，通過審核 +30 🌰。

5. 記錄第一次練習或比賽

中間那顆 ＋，最上面兩格就是 新練習 和 新比賽。 同一頁上方有一張 今日進度，記錄練習、記錄比賽、回報球場狀態， 三件事每天各 +5 🌰。

記完之後，那座球場上有誰你就看得到了

在某座球場留下第一筆紀錄之後，那座球場的資訊卡上會多一行 「另外 N 位球友也在這裡打過」。點開是名單，可以直接送出好友邀請。

這是對等的：你在名單上，你才看得到名單。 在同一座球場打球的人常常整年錯過彼此——一筆紀錄就是你們認得出對方的方式。

練習：必填只有球場

其他全部可以不填。時長預設 60 分鐘，拉一下就好（15 到 180）。 如果你是從打卡的「打完球」那張卡進來的，時長會直接帶入實際待的時間。

選填的部分，有兩個值得填：

  • 練習重點——筆記上方有一排詞：發球、正手、反手、截擊、發球上網、 高壓、切球、腳步、落點、體能、心態。點一下就加進筆記裡
  • 照片——之後要做圖卡的話，這張照片是必要的（見下面）

最後會問「這次練習感覺如何」，五顆球。 打得不順的時候記得誠實給分：給了低分，存檔後 App 會問你是哪裡卡住， 並且把問題整理好帶去問教練。

比賽：球場、對手、至少一盤比分

底下有一排常用比分（6-4、7-5、6-3⋯⋯）點一下就帶進去， 勝負是自動算的。

如果對手是你的球友，記得標記他。打上名字時 App 會問 「這是你的球友嗎？標記他，這場球就會同時進你們兩個人的戰績」。 他那邊會收到一張待確認的卡片，按 確認，計入戰績 之後， 這場球就會出現在他的護照裡。一次記錄，兩個人的紀錄都留下。

200 公尺那條線。 在球場現場記錄（200 公尺內）才拿得到那 5 🌰， 而且大家會在地圖上看到這座球場「有人在打」。 事後回家補記一樣會存下來，練習內容、比分、球場征服都留得住， 只是不計堅果、也不算進總時數。抓不到你的位置時算你有到。

第一次在某座球場記錄，會跳出「新球場達成！第 N 座球場」—— 那是你的球場征服進度，護照上會多一座。

把它做成一張圖卡

練習或比賽附了照片的話，就可以做成一張直式圖卡分享出去。 入口有兩個：剛存完的那一刻會問你「要把這次做成圖片分享嗎？」， 或者之後到 探索 分頁的日記裡，在那張有照片的紀錄上按 分享。

圖卡上會有：

  • 左上角一個標籤——練習，或者「勝 · 雙打」
  • 球場名
  • 練習類型，或者「vs 對手」
  • 一個大數字：練習是時長，比賽是比分
  • 底下是日期和 Tennis Nut 的標

你的照片是背景，可以雙指縮放和拖曳調整位置， 調好的樣子就是匯出的樣子。底下兩顆按鈕：另存為圖片 存進相簿， 或 分享 直接丟給 IG、Threads、LINE。

還有一種：球場紀念圖

這一種是給球場的，不是給某一次練習的。 第一次征服一座球場時，慶祝畫面上有一顆 做張紀念圖分享； 也可以之後從 護照 → 球場征服 → 已征服球場 點任何一座進去補做。

拍一張你和球場的合照，上面會壓上球場名、地址， 還有 第 N 座 · 累計征服 N 座。按 儲存 之後那張照片會留在 這座球場底下，日記的「我的球場」就看得到。

6. 卡住的時候，問專家

諮詢 分頁。上面是 新諮詢，五個類別： 網球技術、網球體能、物理治療、運動營養、運動心理。 選一個就開始。

要寫什麼

  • 標題——一句話總結問題
  • 詳細描述——越具體越好。什麼情況下發生、你已經試過什麼
  • 影片（選填，最長 3 分鐘）——可以當場錄、從相簿選，或貼一個連結。 動作的問題，一段影片勝過三百字
  • 圖片、標籤、年齡都是選填

要多少堅果

開一則諮詢是一則 文字回覆，50 🌰。 之後如果想要教練針對影片做分析，可以在對話裡追加 影片分析， 150 🌰。

聊天不用錢。教練回覆之後你想追問、補充、確認， 在那則對話裡想講幾句都可以，只有正式的解答才扣堅果。 教練全程沒有回覆的話，會自動結案並全額退還。

答案會到哪裡

回到 諮詢 分頁的 我的諮詢，也會有推播。 那一則的狀態會一路從「已送出」走到「專家閱覽中」、「已回覆，等你追問」。 結案的時候會產生一份 處方箋——主要問題、處方、教練評語， 收在你的護照裡，下次遇到同樣的狀況可以翻回來看。
