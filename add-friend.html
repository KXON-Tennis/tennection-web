怎麼加球友

面對面掃一下、或把你的球員 ID 用 LINE 傳過去。 兩條路，看你們現在是不是在同一個球場。

球友名單在護照那一頁，往下滑就是「我的好友」。 點那張卡會打開完整的名單，加人的按鈕都在最上面。

路徑：底部的 護照 → 往下滑到 我的好友 → 點卡片

剛裝好 App 的時候

第一次設定會走到一頁叫「把一起打球的人加進來」，中間就是你的碼。 當下身邊有人，請他點「改掃對方的碼」對著你的畫面掃一下，就加好了。 身邊沒有人也可以先按「傳邀請給球友」，那會產生一段訊息，貼到 LINE 傳給誰都行。

方法一：不在同一個球場，用 LINE 傳

1. 找到你的球員 ID

打開護照，上面那張球員證上寫著「ID · 」加八個字， 例如 ABCD1234。右邊有個複製的小圖示，按一下就複製起來了。

2. 貼到 LINE 傳給對方

直接貼給他就好。也可以按右上角的人＋圖示， 在跳出來的視窗最下面按「或用 LINE 傳邀請給他」—— 那會產生一段完整的訊息，連下載連結和步驟都帶著，對方照著做就行。

3. 對方按右上角的人＋圖示，把 ID 貼進去

他打開 護照 → 我的好友，按右上角那個「人＋」的圖示。 會跳出一個視窗，最上面一格搜尋框——ID 貼在那裡。 你的名字跳出來之後，按加入好友。

不是清單上面那一格。 清單上面那格是用名字在自己已經有的球友裡找人的， 貼陌生人的 ID 進去不會有反應。要貼在右上角圖示跳出來的視窗裡。

4. 你按下勾勾

他送出之後，你的好友頁最上面會出現一列「想加你為好友」， 右邊一個綠色勾勾、一個叉。按勾勾就互相加好了。 你也會收到一則通知，點開直接到這一頁。

方法二：人就在旁邊，掃一下

兩個人各拿各的手機，都到 護照 → 我的好友：

一個人按「我的條碼」

畫面會跳出一個 QR，把手機拿給對方。

另一個人按「掃描」

對著那個畫面掃一下就好，不用打任何字。 掃的那一邊會直接送出，另一邊按勾勾確認。

誰掃誰都可以，結果一樣。護照最上面那張球員證上本來就有一個一樣的 QR， 直接拿那個給人掃也行。

找不到好友頁？ 它不在設定裡，也不在首頁。 底部最右邊的護照，往下滑過「網球數據」，下一格就是「我的好友」。

加好之後

對方去了哪座球場、記了什麼練習，你的日記裡會看得到； 他開的約球會出現在你的首頁；他打的比賽如果標到你， 確認之後會同時進兩個人的戰績。
