加球友，兩步就到

加球友的入口搬到中間那顆「＋」裡，掃碼、傳 ID、貼上 ID 三條路各自走得通；打完球 App 會問你要不要記一筆。

🤝

加球友從四步變兩步

以前要加一個球友，得先想到「好友住在護照裡」，然後往下滑、點進去、再按右上角那個人＋圖示——四次點擊，而第一步就卡住很多人。現在中間那顆綠色的「＋」裡面就有「加球友」。按「掃描」直接開相機，不再跳出一張又要你選一次的表單。

🔢

別人把 ID 傳給你，現在有地方貼

掃碼要兩個人同時在場；「傳邀請」是我發給別人。反過來的情況一直沒有出口——對方用 LINE 把一串 ID 傳過來，你手上有那串字卻不知道要貼哪。好友頁上多了一格專門給它，貼上就能送出邀請。

📝

打完球，App 會問你要不要記一筆

離開球場之後（或下次打開 App 時），首頁會出現一張卡：你今天去了哪座球場，要不要記一筆練習。球場和日期都填好了，時間再改就好。以前要自己想起來、自己從頭填。

🔔

允許了通知卻收不到——修好了

有些人明明在系統設定裡允許了通知，卻一直收不到任何推播。原因是存推播識別碼的時機比登入還早，那一刻程式還不知道是誰，就把它丟掉了，而且不會再試。這一版改成等登入確認之後才存。如果你之前遇過，更新後會自己補上。

🛠

出錯的時候，我們終於看得見

先前有位使用者按分享沒有反應，而我們花了一整個下午才把範圍縮到十行程式碼——因為那個錯誤只發生在他的手機上，我們什麼都看不到。這一版加了錯誤回報：App 出錯時把錯誤訊息傳回來，不含你的紀錄、照片或位置，而且在設定的隱私那一區可以關掉。

其他修正

  • 分享或儲存練習圖片時失敗（截圖做不出來時會自動用小一點的尺寸重試）
  • 按「我的條碼」沒有反應——對話框其實開了，但裡面是空的
  • 邀請訊息裡的球員 ID 跟護照上顯示的不是同一組（前者給的是完整編號，貼了也找不到人）
  • 好友從護照最底下移到「網球數據」下面，不用滑過八個區塊
  • 還沒有球友的人，首頁會直接告訴他怎麼加
  • 練習評分三顆球以下時會問你哪裡卡住，並幫你把問題寫好——送出之前可以先看過、改過
  • 記完練習只打斷一次：分享和問教練放在同一張卡上
  • 「送出諮詢」改成白字，深綠底配黑字看不清楚
  • 專家頁面不分有沒有封面照，版面高度都一樣了
  • 「多專家聯合建議」移到填寫問題那一頁，並拿掉價格——這個服務還在準備中，現在點下去是登記，不會扣堅果
  • 首頁的合作活動可以一則一則關掉；線上活動不再因為沒有座標而被藏起來
怎麼更新？ Android 走 Google Play 會自動更新；iPhone 從 App Store 更新即可。 還沒裝的話，iPhone 從 App Store 下載。
