1. 裝 App、註冊

Tennis Nut iPhone 在 App Store 下載。 Android 照 安裝頁 的步驟裝。

打開 App 是登入頁，三種方式擇一：

  • 使用 Apple 繼續（iPhone）
  • 使用 Google 繼續
  • 使用 Email 繼續——密碼至少 8 碼，忘記了按 忘記密碼?

還不想註冊，可以先按 先看看我們的專家團，看看有哪些教練和專家。

註冊完成就有 300 🌰 堅果入帳。 堅果是 App 裡唯一的點數：打球、記錄、維護球場資料會拿到，問專家時會用到。 完整的表在 第 20 節。

2. 第一次打開

第一次登入會先問你 今天想先做什麼？，四個選項：

  • 找我的球場——直接到地圖
  • 留下今天的練習——直接開練習表單
  • 建立我的網球護照——回答三題，再釘一座常去的球場
  • 找球友或球隊——把一起打球的人加進來

選 建立我的網球護照 的話，三題分別是 你打網球多久了？、 你多常打網球？、你的網球程度是？，接著 釘一座你常去的球場 （下面會列出大家常去的幾座，也可以跳過）。最後 App 會問你要不要開通知—— 建議開，好友到球場、球場有狀況、有人回覆你，都是靠通知告訴你。

這幾題之後隨時可以補：護照 分頁上方的 完成你的網球資料。

首頁會跟著你長

剛註冊的首頁很短，只有 第一步：到球場打一場（記下今天的練習／ 記一場比賽）和附近的球場。記下第一筆之後，歡迎禮的卡片、下一步建議、 大滿貫進度、球友動態會陸續出現；第二筆之後，約球、空檔、你的專業團隊、 合作店家的活動也會出現在首頁。

3. 五個分頁

畫面最下面由左到右：

  • 首頁——今天跟你有關的事：好友動態、快開始的約球、最愛球場現在幾個人、 最新的裝備心得。右上角的堅果數字點下去是 我的堅果，鈴鐺是 通知。
  • 地圖——所有球場，見 第 7 節。
  • ＋（中間那顆）——快速操作，見下面。
  • 紀錄——你的練習、比賽、征服過的球場、收藏。
  • 護照——球員證、數據、諮詢、好友、球隊、球袋。

中間那顆 ＋

按下去分成兩段：

  • 在場邊：新練習、新比賽、回報場況， 下面一顆長按鈕是 沉浸模式。
  • 安排下一次：發起約球、我有空、加球友。

這一顆就是大部分功能的捷徑，下面各節都會用到。

4. 我的球袋

護照 分頁滑到最底是 我的球袋，分成 球拍、球鞋、 網球 三組，每組右邊有 新增，旁邊的數字是目前幾件／上限 （球拍 10、球鞋 6、網球 6）。

球拍

  1. 選 品牌，系列 從清單點選（清單上沒有就自己輸入），填 年份
  2. 拍線：拍線名稱、種類（單股 Poly／多股 Multi／混穿 Hybrid／羊腸 Gut）、線徑
  3. 直線和橫線不同的話，打開 混合穿線（直線和橫線不同），分開填
  4. 磅數（直線／橫線）、穿線日期、在哪家店穿（選填）

每加一支球拍或一雙球鞋 +5 🌰（每種每天最多兩件）。

換線

換了線，點那支拍子 → 修改 → 按 我換線了，日期會變成今天， 改好線和磅數存起來，就多一筆 穿線紀錄。有兩筆以上，會顯示你 平均幾天換一次。該換線的時候，卡片上會出現 穿線提醒， 時間是依你打球的頻率和線的種類算的。

球鞋、網球

球鞋填品牌、型號、年份、開始使用日期。網球只要 品牌 和 型號， 清單裡有 Wilson、Babolat、HEAD、Dunlop、Slazenger、Penn、Tecnifibre、YONEX、 Prince、Teloon 天龍、Tretorn、Artengo 的常見球款。

幫裝備拍照

卡片左下角的相機，或點開裝備選 拍照片。畫面上有一個對準框：

  • 球拍：平放在地上，拍頭朝上，從正上方拍
  • 球鞋：側躺，鞋頭朝右，從正上方拍
  • 網球：拍的是 球罐——直立放好、標籤朝鏡頭，跟罐子同高從側面平拍

送出後 App 會自動去背，做成型錄式的照片，大約一分鐘。這段時間可以先做別的事， 關掉 App 也沒關係，做好就會出現在卡片上。

每支拍打了多久

記練習或比賽時，App 會自動掛上你的 主要球拍 和 主要球鞋， 表單上的 這次用的裝備 也可以換。卡片上會寫打了幾小時、幾場； 點開球拍還看得到練習幾次、比賽幾場、勝敗，以及 換線後打了幾小時。

主要、淘汰、刪除

  • 點開球拍或球鞋，選 設為主要球拍／主要球鞋，卡片上會有「主」字。 你的好友看得到你的主拍和主鞋。
  • 不用了就 淘汰：它會收進 已淘汰，用過的時數和紀錄都留著， 也可以 放回球袋。真的加錯了，在已淘汰裡選 永久刪除。
  • 球拍可以 複製一支相同球拍，同款拍有好幾支的人很好用。
  • 卡片下方的 N 位也用 是用同一款的其他球友，點開可以看心得或按 想聽心得。

5. 裝備心得

球袋標題右邊的 大家的裝備心得，是所有球友寫的裝備心得，最新的在上面。 上方可以篩選 全部／球拍／球線／球鞋／網球。心得右邊的縮圖點一下會放大。

寫一篇

  1. 按 寫一篇
  2. 這篇在講哪一件？——從你的球袋裡挑：球拍、拍上的球線、球鞋、網球
  3. 想比較兩件的話，跟哪一件比？（選填） 再挑一件
  4. 寫內容、發布。這篇所有球友都看得到。

讀到有幫助的心得按 有用。一篇被三位不同的球友按了有用，作者拿 +10 🌰。

想聽心得

在好友名單、球友卡、好友的護照上看到別人的主拍或主鞋，可以按 想聽心得。 主人會看到「有幾位球友想聽」，寫了之後，按過的人都會收到通知。

首頁也會放最新的兩篇心得。按 × 會先收起來，有人發新的一篇時會自己回來； 想馬上叫回來，到 設定 → 首頁的裝備心得 → 在首頁顯示。

6. 加好友、跟好友聊天

面對面：掃一下

在 護照 最上面的球員證上，有你的 球員證 QR，旁邊是 掃描對方。

  1. 一個人亮出自己的球員證 QR
  2. 另一個人按 掃描對方，對著 QR 掃一下，好友邀請就送出了
  3. 對方按 接受，就成為好友

掃到的如果是球隊的 QR，會直接加入那個球隊。

不在旁邊：傳 ID

護照 的 我的好友 → 新增，或中間 ＋ 的 加球友。 裡面可以 貼上 ID 搜尋，也可以按 或傳我的 ID 邀請他， 用 LINE 把你的 8 碼球員 ID 和下載連結傳出去。球員證上點 ID 也會直接複製。

在球場上認識的人

在同一座球場或同一個城市留下過紀錄的球友，會出現在球場卡的 這一帶的球友。 對還不認識的人送邀請時，要先 跟他說一句（有現成的句子可以一鍵選）。

收到的邀請在好友頁上方的 待確認邀請，按 接受 或 拒絕； 14 天沒回覆會自動收掉。

加了好友之後

  • 他到球場，你的手機會響：「○○ 現在在 ×× 打球」
  • 看得到他的護照：數據、主拍主鞋、球隊、賽事成績
  • 約球可以只給好友看，也可以直接點名他
  • 記比賽時標他，他確認後，這場也進他的戰績

跟好友聊天

打開好友的護照，右上角的對話圖示就是 傳訊息。聊過的人會列在好友頁的 訊息，有未讀的會顯示數字。每一則訊息都會推播；某一段對話不想被吵， 點右上角的鈴鐺靜音，訊息只會進通知列表。

只有互相是好友的人可以傳訊息。不想收任何訊息，到 設定 關掉 好友可以傳訊息給我（關掉之後你也不能傳給別人）。

好友護照右上角的 ⋯ 有 檢舉、封鎖這個人、解除好友。 封鎖會同時解除好友，封鎖名單在 設定 → 已封鎖的人。

7. 地圖怎麼看

點的顏色是場地材質

藍色是硬地、橘紅是紅土、綠色是草地和人工草、灰色是水泥、紫色是 PU， 小小的咖啡色點是練習牆。地圖上的 圖例 可以隨時打開對照。

外圈是現在的狀況

  • 橘色外圈：現在有人在打，上方寫「N 人在打」
  • 淡橘色外圈：今天有人來過
  • 紅色外圈：有狀況（客滿、溼滑、損壞、暫停開放），上方直接寫是什麼狀況
  • 白色虛線外圈：新投稿的球場，等待審核

上方的切換

  • 今日足跡：只看今天有人去過的球場和人次
  • 找球友：哪些球場有人排了空檔、有人約球
  • 最愛、球隊、牆壁

更多條件在 篩選球場：已拜訪、室內、場地類型、費用（免費開放、付費開放⋯⋯）、 縣市、國家。底圖可以換成街道、深色、衛星或正射影像。

搜尋

搜尋框可以打球場名、地址或地標，也找得到合作店家（見 第 18 節）。

點開一座球場

由上而下大致是：

  • 右上角 ♥ 加入最愛——這一帶的空檔和約球會出現在你的首頁， 球場有狀況也會通知你
  • 紀錄（帶著這座球場開練習表單）和 導航
  • 面數、材質、費用、燈光、室內外，以及 N 位球友打過
  • 現在的狀況、營業時間、球友補充、勝場王
  • 球場照片、現在在場上的好友、在這裡的約球（約這裡）
  • 有空可以來這裡的球友、球隊團體、這一帶的球友、辦過的盃賽
  • 附近的合作店家

常去的球場，打卡之後 App 會問你要不要 釘成主場，釘了之後那座球場的狀況和今天誰在打， 會直接出現在首頁。

8. 去練習：打卡與練習紀錄

到了球場，打卡是自動的

在球場待滿五分鐘，App 會自己記一筆打卡 +1 🌰； 跳出「你在 ×× 打球嗎？」時按確認 +2 🌰。 第一次到一座球場另外 +15 🌰，那座球場就算 征服 了。

記一筆練習

中間 ＋ → 新練習。必填只有球場，在球場附近會自動選好。其他可以填：

  • 日期、開始時間、時長
  • 練習類型：自主練習、球機練習、對打練習、教練課、定點練習、比賽練習、體能訓練
  • 這次練習感覺如何？——點一到五顆球
  • 這次用的裝備、筆記與標籤
  • 一張照片，可以選 也放到球場頁（公開）

人在球場 200 公尺內（或今天已經在那裡打過卡）記錄，拿 +5 🌰， 練習每天最多三次。記完之後，那座球場的 N 位球友打過 就點得開了， 看得到還有誰也在這裡打球。

9. 記一場比賽

  1. 中間 ＋ → 新比賽
  2. 這場是：自由對打 或 賽事（賽事要填賽事名稱）
  3. 選 單打 或 雙打，填對手（和搭檔）。最近一起打過的人和好友會列成快速選項
  4. 填比分：一般分盤，或只打搶七；最多五盤，勝負會自己算
  5. 存檔。接著還要記下一場，按 儲存，再記一場，球場和日期會留著

標了好友當對手或搭檔，他會收到通知，在 App 裡選 確認，計入戰績、 確認，但不計入戰績 或 這不是我。確認之後，這場會進兩個人的戰績。 跟練習一樣，在球場附近記錄 +5 🌰，每天最多三次。

之後要改，點開那一場可以改日期、時間、裝備和筆記。

10. 做成圖卡分享

點開任何一筆練習或比賽，按分享，有三種尺寸：貼文 3:4、限時動態 9:16、 透明貼紙（白字或深色字）。做好之後 存到相簿、分享到 IG 限動， 或 更多 用其他 App 傳。

選 分享到 IG 限動 時，挑一張自己的照片或一段影片當背景，貼紙會疊在上面 一起送進 Instagram，在 IG 裡拖一下位置、按發佈就好。 護照上的 做張圖卡、征服地圖、球隊頁也都能做圖卡。

11. 紀錄分頁

上面三個分頁：

  • 我的紀錄：練習和比賽照日期排成一條時間軸，可以切 全部／練習／比賽， 也看得到 我的統計 和 比賽統計
  • 征服球場：你去過的每一座球場、一年一年的歷程、 還有幾座等你收，看地圖 是你自己的征服地圖
  • 我的收藏：見 第 19 節

12. 網球護照與大滿貫

護照 分頁最上面是你的 球員證：頭像、加入日期、主場 （最近 90 天最常去的球場）、持拍手、自我介紹、獎盃和 QR。鉛筆圖示改個人資料， 調色盤圖示換護照外觀。往下依序是網球數據、我的諮詢、球場征服、賽事成績、 成就徽章、我的好友、我的球隊、我的球袋。

大滿貫獎盃

在對的季節、對的場地拿下 7 場勝利，就拿到一座獎盃 +300 🌰，還會解鎖一套護照外觀：

獎盃月份條件
澳網1–3 月硬地
法網4–6 月紅土
溫網7–8 月草地、人工草
美網9–10 月硬地、天黑之後
年終賽11–12 月室內至少 3 勝，而且當年拿過 3 座大滿貫

算數的勝場：對手或搭檔是 App 裡的球友、那天你在那座球場有打卡， 每天最多算兩場。首頁的大滿貫卡片會顯示目前進度。

13. 排空檔、約球

說出你什麼時候有空

中間 ＋ → 我有空 → 設定我的空檔：

  • 時間：今天或指定日期、幾點到幾點，也可以 整天；可以連續 2 週或 4 週
  • 地點：指定球場、某個地區 或 都可以
  • 想打什麼：單打、雙打、對抽／練球、發球／接發、截擊／網前、多球／餵球、計分／比賽
  • 程度、歡迎新手、一句備註
  • 誰看得到：只有好友、公開，或你的某個球隊

按 貼出來。跟好友的空檔重疊時，App 會告訴你重疊多久。

找人、約一場

地圖切到 找球友，點有人的球場，有空可以來這裡的球友 裡按 約他。 或在球場卡按 約這裡、中間 ＋ 按 發起約球：

  1. 時間（預設兩小時後、90 分鐘）、單打或雙打、用球
  2. 找誰（選填）——＋ 指名球友 直接邀請
  3. 誰看得到：只有好友、你的球隊、所有把這座球場加最愛的人，或 只有受邀的人
  4. 按 發出邀約

看到別人的約球按 我要去；臨時不能去按 不去了，同一場的人都會收到通知。 被點名的人可以先問清楚，再決定加入或 婉拒。

約球對話與到場

名單上有兩個人以上，就會開一個 約球對話，可以講誰帶球、場地費、 晚到或在哪裡等，約球結束後三小時關閉。開始前兩小時，首頁會出現到場卡， 到了按 我到了，大家看得到幾個人已經到。

14. 球隊

  1. 護照 → 我的球隊 → 建立球隊，或在球場卡按 在這裡建隊
  2. 填隊名、選主場
  3. 按 邀請加入：給隊友掃 QR，或傳邀請碼／連結

用邀請碼或 QR 加入是直接加入；在球場卡或球隊頁按 申請加入 的，要等隊長核准。 每個人最多建立 5 支球隊。

球隊頁

  • 球隊對話：隊員之間的聊天室。打 @ 會列出隊員，點選就能點名， 被點名的人一定會收到推播。右上角的鈴鐺可以關掉這一隊的推播
  • 球隊圖卡：今天全隊打了什麼，做成一張圖分享
  • 隊內動態、一起約過的球、全隊去過的球場
  • 隊長可以設定 隊色（在沉浸模式裡會亮起來）、轉移隊長

約球時「誰看得到」選你的球隊，就只有隊員看得到。

15. 沉浸模式

地圖上的 沉浸模式 按鈕，或中間 ＋ 裡的 沉浸模式。地圖會傾斜成立體的，球場變成 3D 模型， 你的頭像周圍有一圈雷達。

面對面

雷達範圍是身邊 50 公尺。旁邊也開著沉浸模式的球友會出現在雷達上， 點他可以 加好友、記這場比賽、約下次——兩個人都點了才算數。 用這個方式記的比賽，在場的人當下就確認了，直接算進勝場王和大滿貫。

現在想打

選 找單打對手、找雙打搭檔、想對拉練球 或 新手找新手， 會貼出一段兩小時的公開空檔，附近的人看得到。

勝場王

每座球場最近 90 天贏最多場（而且對手確認過）的人，就是那座球場的勝場王， 頭像會浮在 3D 球場上方，球場底部亮起他球隊的顏色。

你人在球場 200 公尺內時，頭像會出現在那座球場上，其他球友在地圖上看得到。 你在街上的位置不會顯示給任何人。

16. 諮詢專家

打球卡住了，可以問真人專家。入口在 護照 → 我的諮詢 → 開始諮詢； 記完一筆練習後的 問問教練、收藏影片片段的 帶這段問教練 也會進來。

  1. 選擇諮詢類型：網球技術、網球體能⋯⋯
  2. 寫標題和描述，可以附一段 3 分鐘內的影片或連結、照片
  3. 確認諮詢 → 送出諮詢
項目堅果
開始一則諮詢（文字回覆）50 🌰
追加專業提問：文字回覆50 🌰
追加專業提問：影片分析150 🌰
跟教練來回聊天0

專家在時限內回覆（文字 5 天、影片 72 小時）；超過時限，那一題的堅果自動退回。 兩天沒有回覆會換一位專家接手；七天都沒有動靜會自動結案， 專家完全沒回覆的話全額退回。

結案時專家會寫一份 處方箋：主要問題、處方、評語。它會留在你的 行動建議， 也會出現在 賽前複習。

17. 貢獻球場資訊

地圖上的球場資料是球友一起補起來的。你可以做五件事，每一件都有堅果：

做什麼堅果什麼時候入帳
新增球場或牆壁+50審核通過後
回報即時場況+15送出就入帳，同一座球場每 30 分鐘一次
補充或修正資訊+15審核通過後
回報封閉期間+15封閉生效後
上傳球場第一張照片+10送出就入帳

新增球場或牆壁

地圖上找不到你打球的地方，就把它加上去。

  1. 在 地圖 分頁按 新增球場或牆壁。地圖會換成空照圖，看得到真正的球場線
  2. 拖曳地圖，把畫面中央的紅色圖釘對準球場。人就在球場的話，按定位鈕會直接跳到你的位置； 也可以用 搜尋地址 或 輸入經緯度 先跳過去
  3. 對準了按 位置確認
  1. 填 回報新球場或牆壁：球場名稱 是必填，寫大家平常叫它的名字， 例如「中路運動公園網球場」
  2. 選 場地材質（下面說明怎麼選）
  3. 知道的話補上 面數、地址、電話、有夜間照明、室內球場
  4. 按 送出（核可後 +50 堅果）

球場、牆壁、練習場怎麼選

場地材質 這一格同時決定它是哪一種地方：

  • 網球場：選它的地面材質——硬地、紅土、草地、人工草、砂地人工草、水泥、PU、地毯， 不確定就選 其他。選單上每一種旁邊的顏色，就是它在地圖上的顏色
  • 練習牆（一個人對著牆打的那種）：選最下面的 牆壁。 名稱可以寫「○○公園練習牆」
  • 室內練習場（打擊場、室內練習空間）：選 練習場

練習牆在地圖上是小小的咖啡色點，地圖上方切到 牆壁 就只看牆。 在牆壁可以記練習；比賽和約球要選在球場。

送出之後：審核

送出之後，你自己的地圖上馬上看得到它，外面圍著一圈 白色虛線， 意思是「新投稿，等待審核」。管理員核對位置和資料，通過之後白色虛線消失， 所有球友都看得到它，你的帳上也會多 +50 🌰。

回報即時場況

到了球場，用一分鐘告訴大家現在能不能打：

  1. 中間 ＋ → 回報場況，選你所在的球場
  2. 選 即時狀態回報，再選 目前球場狀態： ✅ 可正常使用、💧 場地溼滑、⚠️ 設施損壞、🚫 場地客滿、🔒 暫停開放
  3. 要補充可以寫一句，例如「只有 A 場積水，B 場可用」，按 提交回報 (+15 堅果)
  • 人要在球場 200 公尺內才能回報
  • 隨時都可以回報；堅果是同一座球場每 30 分鐘給一次
  • 回報的狀態會顯示在球場卡上，地圖上那座球場的外圈也會變色（有狀況是紅色）， 六小時後自動淡掉，等下一個人回報
  • 把這座球場加了最愛的人會收到推播：今天第一個回報的人一定會通知（包括「可正常使用」）， 之後狀況有變才再通知

補充或修正資訊

名稱、面數、燈光、開放時間這些不常變的資料，有缺或有錯就補：

  1. 在地圖點開球場，右上角 ⋮ → 補充 / 修正資訊 （或中間 ＋ → 回報場況 → 基本資訊勘誤）
  2. 在 補充或修正球場資訊 裡改你知道的欄位：球場名稱、場地類型、球場數量、照明、室內、 對外開放、場地租借、開放時間、開放說明、電話、官方網站、地址
  3. 補充說明（選填） 寫只有常客才知道的事，例如「燈要自己到電箱開」
  4. 按 提交勘誤

管理員審核通過後資料就會更新，你拿 +15 🌰； 你寫的補充說明會署名顯示在球場資訊卡上。

表單最下面的 回報問題 有三種：

  • 這個球場已廢棄／拆除：球場已經永久消失。審核通過後會從地圖移除， 你拿 +15 🌰。只是暫時不開放的話，請用下面的「回報封閉期間」
  • 這不是網球場：地圖上這個點根本不是網球場，查證後移除
  • 回報封閉期間（公告、維修、比賽）：見下一段

回報封閉期間

球場貼了「整修暫停開放」「某某盃比賽借用」這類公告時，用這個功能讓大家事先知道， 也避免有人約在那幾天。

  1. 球場卡 ⋮ → 補充 / 修正資訊 → 最下面的 回報封閉期間（公告、維修、比賽）
  2. 選種類：封閉、維修 或 舉辦比賽
  3. 填 開始日期 和 結束日期
  4. 拍一張 公告照片，需要的話寫一句 說明（選填），按 送出

封閉、維修 的規則：

  • 要人在球場 100 公尺內 才能回報，每人每天最多 5 筆
  • 附上公告照片：立刻生效。球場卡上會出現「維修中・至 11/15」， 這段期間不能在這裡約球，已經約在那幾天的人和把球場加最愛的人都會收到通知， 你拿 +15 🌰
  • 沒有照片：先只顯示提醒，大家照樣可以約球。之後有兩位球友到現場按 還是封閉，就會生效
  • 同一段期間已經有人回報過，你再回報會算成一次確認
  • 期間最長一年，太長的請分段回報；已經過去的日期不能回報

舉辦比賽 不用人在現場（主辦方通常事先就知道），送出後由管理員核可，核可後那段期間不能約球。

看到封閉提示，但球場其實開著？

人在現場的話，球場卡上的封閉提示有兩顆按鈕：

  • 其實開著：封閉會改回只顯示提醒，大家又可以約球
  • 還是封閉：幫這段封閉做確認

封閉期間只擋約球。練習、打卡、記比賽都照常，球場開著的時候照樣記得到。

上傳球場照片

球場卡裡的 球場照片 按上傳，拍一張現場照片。人要在球場 200 公尺內； 一座球場的第一張照片拿 +10 🌰。 照片被兩個人檢舉會先隱藏。
