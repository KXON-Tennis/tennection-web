怎麼加球友

面對面掃一下、把 ID 傳給他，或把別人給你的 ID 貼上。 三條路，看你們現在是不是在同一個球場。

入口在中間那顆綠色的「＋」裡——按下去， 清單裡就有「加球友」。兩步就到，不用去翻護照。

路徑：中間的 ＋ → 加球友

也可以從 護照 → 我的好友 進去，同一頁。 好友那一格就在「網球數據」下面，不用滑到最底。

方法一：人就在旁邊，掃一下

兩個人各拿各的手機打開那一頁，然後分工—— 這是最常卡住的一步：兩個人都打開自己的條碼互看，就沒有人在掃。

一個人按「我的條碼」

畫面會跳出一個方形條碼，把手機拿給對方看。

另一個人按「掃描」

相機會直接打開，對著那個畫面掃一下就好，不用打任何字。 掃的那一邊會直接送出邀請，另一邊按勾勾確認。

誰掃誰都可以，結果一樣。護照最上面那張球員證上本來就有一個一樣的條碼， 直接拿那個給人掃也行。

方法二：不在同一個球場，把 ID 傳給他

1. 按「或傳我的 ID 邀請他」

在好友頁上，兩顆按鈕下面就是這一行。 按下去訊息會自己寫好——你的球員 ID、下載步驟都在裡面。

2. 挑一個人傳出去

LINE、訊息、WhatsApp 都行。 他收到的是一則完整的說明，照著做就可以。

3. 你按下勾勾

他把 ID 貼進去送出之後，你的好友頁最上面會出現一列「想加你為好友」， 右邊一個綠色勾勾、一個叉。按勾勾就互相加好了。 你也會收到一則通知，點開直接到這一頁。

方法三：別人把 ID 傳給你了

對方傳過來一串像 EA091DDA 的字，那就是他的球員 ID。 好友頁上有一格專門給它：

「已經拿到球友的 ID 了？」

兩顆按鈕下面那張卡，把 ID 貼進去，按加好友。 邀請就送出去了，等他按勾勾。

ID 在哪裡看？ 你自己的在護照最上面那張球員證上，寫著「ID · 八個字」， 旁邊有一個複製圖示。傳邀請時附的就是這一組。

加好之後

對方去了哪座球場、記了什麼練習，你的日記裡會看得到； 他開的約球會出現在你的首頁；他打的比賽如果標到你， 確認之後會同時進兩個人的戰績。
