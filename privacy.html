Tennis Nut 隱私權政策

最後更新日期：2026 年 11 月 12 日

歡迎使用 Tennis Nut（以下簡稱「本 App」）。本隱私權政策說明本 App 開發者（以下簡稱「我們」）會如何收集、使用、儲存與分享您的個人資料。請您於使用本 App 前詳細閱讀本政策。當您下載、安裝或使用本 App，即表示您已閱讀、理解並同意本政策內容。

1. 我們收集的資料

我們僅收集為提供本 App 服務所必要之資料，包含以下類別：

1.1 帳號與個人檔案資訊

  • 您透過 Email、Apple ID 或 Google 帳號登入時提供的:電子郵件地址、姓名、個人頭像、第三方識別碼(Apple 的 sub、Google 的 user ID)。使用 Apple 隱藏電子郵件功能時，我們僅取得 Apple 中繼的轉發位址，不會收到您的真實 Email。
  • 您主動於個人檔案中填寫的:暱稱、性別、慣用手、球技程度、所在地區等。

1.2 使用紀錄

  • 您建立的練習紀錄、比賽紀錄、影片連結、文字回饋。
  • 您與教練、球友間的對話內容，包含好友聊天（限互為好友、雙方都開啟時）、約球對話與球隊對話。
  • 您對球場的評價、回報的場地狀態。
  • 您加入好友、收藏球場、消耗點數等行為資料。
  • 您選擇公開的內容：自我介紹、球技程度、主要使用的球拍與球鞋、裝備心得，所有使用者都看得到；練習或比賽的照片可由您選擇分享到球場頁面。

1.3 位置資訊

  • 在您主動授權的前提下，本 App 會使用您的 GPS 位置顯示鄰近球場、自動帶入最近的球場。
  • 自動打卡：App 開著時約每 2 分鐘確認一次您的位置；當您在球場 200 公尺內停留滿 5 分鐘，會建立一筆打卡紀錄（球場、時間）。打卡後，您的好友會收到您到場的通知；把該球場加入最愛的使用者會收到一則不含您名字的「有人在打球」通知。
  • 沉浸模式：您開啟沉浸模式且人在球場附近時，您的頭像會顯示在該球場的位置上，所有使用者都看得到。我們只畫在球場座標上，不會顯示您在街上的即時位置。
  • 面對面：雙方都開著面對面畫面時，會比對兩支手機的位置，50 公尺內才能互相看到。
  • 挑戰：部分挑戰以您在球場（或練習牆）現場的 GPS 位置作為證明。
  • 您可隨時在 iPhone「設定 → Tennis Nut → 位置」或 Android「設定 → 應用程式 → Tennis Nut → 權限 → 位置」中關閉本權限。關閉後不會自動打卡，仍可手動記錄練習與比賽。

1.4 相機與相簿

  • 在您主動授權的前提下，本 App 會於以下情況使用相機：QR Code 掃描（加好友、加入球隊）、拍攝球袋裡的球拍／球鞋／網球（照片會經過自動去背處理）、練習或比賽照片、案件附加圖片；並於您從相簿選擇圖片或影片附加到上述內容時讀取相簿。
  • 我們不會在您未操作的情況下啟用相機或讀取相簿。

1.5 推播通知識別碼

  • 為傳送即時通知（教練回覆、好友訊息等），本 App 會透過 Firebase Cloud Messaging（FCM）取得裝置的推播 Token。

1.6 裝置與技術資訊

  • 為了改善服務與排查錯誤，本 App 可能蒐集裝置型號、作業系統版本、語言設定、App 版本、Crash 紀錄。

1.7 讓附近的球友看得到我（可關閉）

  • 這個開關在 App 內「設定 → 隱私 →『讓附近的球友看得到我』」，預設開啟。
  • 開啟時：您停留確認的打卡會在 2 小時內計入該球場的「N 人在打」人數（人數本身不帶名字）；同時，您的名字與球技程度會出現在球場卡與「這一帶的球友」名單上，同一座球場或同縣市打球、還不是您好友的使用者看得到。
  • 關閉時：您不計入球場人數，也不會出現在上述名單上；同時您也看不到「這一帶的球友」。
  • 沉浸模式的頭像顯示（見 1.3）由您是否開啟沉浸模式決定，不受這個開關影響。
  • 好友到場通知只在您與對方互為好友時發送，不受這個開關影響；要停止只能解除好友。記錄練習或比賽時也可以單筆勾選「匿名顯示在地圖活動上」。

我們不會主動蒐集:通訊錄、簡訊、健康資料、Apple ID 密碼、信用卡資料。

2. 我們如何使用您的資料

  • 提供核心服務:登入驗證、紀錄保存、好友互動、球場推薦、教練配對。
  • 個人化體驗:根據您的位置與紀錄，計算 Court Heat、推薦相關球場與內容。
  • 通訊與通知:傳送您訂閱的推播通知與系統訊息。
  • 服務改善與除錯:分析使用情況、修復 Bug、預防濫用與舞弊。
  • 法令遵循:必要時依法律或司法機關要求保留或揭露相關資料。

3. 我們不會做的事

  • 我們不會販售您的個人資料給第三方。
  • 我們不會將您的對話內容、影片或位置資料用於廣告投放。
  • 我們不會未經您同意將您的個人資料提供給其他使用者，但您主動分享於 App 中之公開內容（如球場評論、暱稱）除外。

5. 資料儲存位置與保留期限

  • 您的資料儲存於 Supabase 託管之伺服器，位於澳洲雪梨。
  • 您可隨時於 App 內「設定 → 危險區域 → 永久刪除帳號」自助刪除；送出後個人資料與相關紀錄即時永久移除,Apple 中繼 Email 等第三方識別碼亦同步解除綁定。
  • 您在約球對話、球隊對話中說過的話屬於共同對話，刪除帳號後會保留在對話中，但不再顯示您的身分、也無法連回您的帳號。您寫的裝備心得與心得底下的留言也一樣保留，署名改為「未知帳號」；想一併刪除，請在刪除帳號前先自行刪掉，或來信協助。有教練案件紀錄的教練帳號需來信協助刪除。
  • 練習與比賽紀錄會持續保留，直到您主動刪除。
  • 諮詢案件中的對話、圖片與影片保留至您刪除帳號為止；案件結案後仍可於 App 內查閱。
  • 法令要求保留之資料（如交易紀錄）依相關法律期限保存。

6. 您的權利

您有以下權利，可隨時透過 App 內功能或來信與我們聯繫行使:

  • 存取:要求查閱我們持有的您個人資料副本。
  • 更正:更新或修改不正確的資料。
  • 刪除:於 App 內「設定 → 危險區域 → 永久刪除帳號」即可自助刪除；部分匿名化統計資料(如球場總計次數)可能保留但無法與您連結。
  • 退出:撤回您先前授予的權限（位置、相機、相簿、推播）。
  • 資料可攜:要求以結構化、機器可讀格式取得您的資料副本。

7. 兒童隱私保護

本 App 不主動針對 13 歲以下兒童提供服務，亦不會故意蒐集其個人資料。若您為未成年人，請在父母或法定監護人同意下使用本 App。如我們知悉曾誤蒐集 13 歲以下兒童資料，將立即刪除。

澳洲使用者：依澳洲法規，在澳洲使用本 App 須年滿 16 歲。手機地區或您選擇的市場為澳洲時，App 會在登入後詢問一次出生年份。我們只儲存年份、不儲存完整生日，且不會向其他使用者顯示。未滿 16 歲者，我們不會儲存所填的年份，且無法繼續使用本 App；畫面上可直接刪除帳號並登出。

8. 國際資料傳輸

由於本 App 之主要資料庫位於澳洲雪梨，部分處理服務位於台灣（Google Cloud asia-east1），推播服務由 Google Firebase（資料中心可能位於美國等地）提供，您的資料可能跨境傳輸至上述地區。我們會採取合理的安全措施確保資料傳輸安全。

9. 安全措施

  • 所有與後端伺服器之間的網路傳輸均使用 HTTPS / TLS 加密。
  • 帳號密碼經安全雜湊處理，不以明文儲存。
  • 推播 Token 與 Session Token 受 OS Keychain / Secure Storage 保護。
  • 即使如此，無任何網路系統可保證 100% 安全；如發現重大資料外洩事件，我們將依法律規定通知受影響之使用者。

10. 政策變更

我們可能不定期更新本政策。重大變更將透過 App 內通知或 Email 告知您；您於變更生效後繼續使用本 App 即視為接受新版政策。建議您不定期回到此頁面查閱最新版本。
